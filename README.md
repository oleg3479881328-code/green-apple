# Green Apple

Repo-native AI project scaffold.

This repository uses agent files and project-state files as the coordination layer for ChatGPT, Codex, and other AI runtimes.

Start here:

1. Read `AGENTS.md`.
2. Read `PROJECT_STATE.md`.
3. Read `NEXT_TASK.md`.
4. Select the required agent from `agents/`.
5. Work only inside the allowed scope.
