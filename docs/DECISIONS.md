# DECISIONS.md

## Accepted decisions

### D-001 — Repo as source of truth

The GitHub repository is the single source of truth for project state, agent roles, documentation, and handoffs.

### D-002 — Agents as portable files

Agents are stored as Markdown role files in `agents/`, not as platform-locked assistants.

### D-003 — MVP-first rule

The project must prioritize minimal working progress over over-engineering.

### D-004 — Product direction

Green Apple is a landing page for selling green apples.

### D-005 — Static MVP

The first MVP must be a static one-page website using simple HTML and CSS. No backend, database, payment system, or inventory logic in the first implementation.
